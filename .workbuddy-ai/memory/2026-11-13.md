# 2026-11-13

## 青瓷拼音（qingci-ime）MVP 完成

- 技术路线（用户确认）：Ubuntu 26.04.1 LTS + **Fcitx5** 框架，**Rust 核心引擎 + C++ 插件胶水层**，功能范围为全拼+简拼+词频排序 MVP。
- 结构：
  - `core/`（Rust qingci-core，crate-type staticlib+rlib）：syllable.rs（380 音节表+多路径 DP 切分）、dict.rs（三种倒排键：全拼/末字全拼/全简拼）、engine.rs（权重打分 1000/800/600/350、用户词频学习持久化）、ffi.rs（C ABI，QingciResults 字符串数组）、bin/qingcli.rs。
  - `core/data/qingci.dic`：约 700 条演示词库，格式 `词条\t词频\t音节…`。
  - `addon/`（C++）：InputMethodEngineV2 实现、CommonCandidateList 分页、propertyFor 状态管理；CMake 用 `add_fcitx5_addon`；addon conf 的 `Library=` 需写 `libqingci`（fcitx5 不自动补 lib 前缀，已读源码 sharedlibraryloader.cpp 确认）。
  - `scripts/build-ubuntu.sh` 一键构建；`docs/BUILD-UBUNTU.md` 依赖/安装/启用/排错。
- 验证：19 个单元测试全过；qingcli 端到端输出正确（nihao→你好、nh→你好、wm→我们、xi'an→西安、nih→你好、shijie→世界）。
- 踩坑：音节表初版漏 `ne`（呢）导致 1 条词条被跳过；纯字母简拼（nh/wm）需单独的「每字母一个音节」查询分支。
- git：本地仓库初始提交 2 个（941cbe5、3294dc7），**尚无远程**；后续按用户惯例走 PR 流程需先建远程（如 luoqingciya/qingci-ime）。
- 待办：Ubuntu 侧实际编译验证插件、完整词库导入、模糊音/双拼。
